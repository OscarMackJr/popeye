<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Popeye Terraform -> caller VNet | Only linked if networking grants join permission |
| Key Vault -> gateway identity | Vault-scope Secrets User can read the reader DSN |
| Terraform state | Holds reader password (sensitive) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | Wrong or hijacked env DNS zone | mitigate | Zone name/IP derived from module outputs, links with registration disabled, count-gated default false |
| T-05-02 | Elevation | Terraform changing networking-owned peering or Postgres caller link | mitigate | Nothing imported or created for peering or the caller-side Postgres link (D-17); plan must show none |
| T-05-03 | Info disclosure | Gateway UAMI can read litellm-reader-dsn | accept | Read-only role limited to one table; documented; Phase 3 narrows to a view |
| T-05-04 | Info disclosure | Reader password in state/KV | mitigate | random_password into KV only; state is Entra-auth backend, already sensitive |
| T-05-05 | Info disclosure | Reading secret value to verify existence | mitigate | Use `secret list` names only |
| T-05-SC | Tampering | Package installs | accept | None introduced |
</threat_model>
