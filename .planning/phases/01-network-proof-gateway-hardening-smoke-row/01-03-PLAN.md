## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator session -> Key Vault | Master key and DB admin DSN read at runtime in an interactive az login session |
| VM -> gateway | Smoke and lockdown HTTP calls cross the peering to the internal FQDN |
| script -> Postgres | Reader DSN, SELECT only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Info disclosure | Master key / admin DSN / smoke key in output | mitigate | Held in locals/SecureString only; acceptance greps forbid Write-Host of secrets; output limited to status, ids, timestamps |
| T-03-02 | Elevation | Smoke key reaching management routes | mitigate | Explicit allowed_routes list (not key_type llm_api); lockdown script with positive control proves 401/403 is route-based |
| T-03-03 | Tampering | Reader role with write access | mitigate | SQL grants SELECT on one table only; verification query asserts no INSERT/UPDATE/DELETE; Psql script has no write SQL |
| T-03-04 | Info disclosure | Prompts/responses readable via table-wide SELECT | accept | store_prompts_in_spend_logs false so columns are empty; assertion checks messages/response are {}; Phase 3 view is the fix |
| T-03-05 | Repudiation | Reusable long-lived smoke key | mitigate | 24h duration, 0.25 budget, blocked (not deleted) after evidence (D-10) |
| T-03-06 | Spoofing | Dead key false-passing negative tests | mitigate | Positive control /v1/models must return 200 |
| T-03-SC | Tampering | Package installs | accept | None introduced |
